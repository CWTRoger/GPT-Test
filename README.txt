True Vine Game System v3.3

Run:
1. Open index.html directly, or host with local static server.
2. Designed for 2560x1440 projection with automatic scale fallback.

Features:
- 4 game modes: Memory, Bible Quiz, Random Question, Verse Order
- Team count & score system
- Timer system
- Excel/CSV import (question banks)
- Card flip animation (0.4s)
- Audio feedback (ding/bell synthesized)
- v3.3 design docs embedded in UI (wireframe, AI generator prompt, DB schema, state machine)
