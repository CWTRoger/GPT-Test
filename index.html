📊 Database Schema

Table: questions
- id (uuid)
- mode (memory|quiz|random|verse)
- question (text)
- answer (text)
- option_a, option_b, option_c, option_d (text)
- reference (text)
- verse_segments (json)
- difficulty (int)
- tags (json)
- created_at, updated_at

🎮 State Machines

Memory: idle -> shuffling -> firstPick -> secondPick -> resolve -> completed
Quiz: idle -> presenting -> locked -> feedback -> next -> completed
Random: idle -> drawing -> displayed -> acknowledged -> drawing/completed
Verse: idle -> shuffled -> arranging -> validating -> success/retry -> completed
Global: setup -> running -> paused -> ended
